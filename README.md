### 🎨 **Key Features**

*   🟢 **[Dynamic Initialization]**: Validates deposits in real-time.
*   🔴 **[Safety Lock]**: A mandatory **250 Taka** file cost is added but protected from withdrawal.
*   🟡 **[Crash-Proof]**: Advanced `try-except` logic ensures typos don't break the system.
*   🔵 **[Smart Status]**: Displays your *Total Balance* vs. *Withdrawable Cash*.

---

### 🏛️ **Importance**

1.  **Financial Stability**: Ensures the bank always retains a 250 Taka operational fee.
2.  **User Efficiency**: No more double-typing. Validates inputs until they are correct.
3.  **Logical Precision**: Uses Object-Oriented Programming (OOP) to keep data separate and safe.

### 📋 **Operational Overview**


| Function | Requirement | Output |
